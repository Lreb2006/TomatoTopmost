# 发布前人工检查

- [ ] 用普通用户安装，确认无需管理员权限。
- [ ] 确认开始菜单和系统的已安装应用中均能找到助手。
- [ ] 确认默认不添加开机启动。
- [ ] 开启助手置顶后，切换普通窗口，番茄ToDo仍可见。
- [ ] 关闭助手置顶后，番茄ToDo可以被普通窗口覆盖。
- [ ] 确认关闭番茄ToDo自身的置顶开关不会被误认为关闭了助手。
- [ ] 确认置顶不会改变输入焦点、位置或尺寸。
- [ ] 最小化番茄ToDo，确认不会自动弹回。
- [ ] 退出并重新打开番茄ToDo，确认助手重新识别主窗口。
- [ ] 重复打开助手，确认不会出现多个托盘实例。
- [ ] 开启再关闭开机启动，确认仅修改当前用户的助手启动项。
- [ ] 卸载后确认助手、快捷方式和其开机启动项已清理。
- [ ] 确认番茄ToDo及待办数据保持不变。
- [ ] 在第二台 Windows 电脑上复查安装与卸载。
