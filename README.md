# 番茄置顶助手

## 安装

适用于 Windows 10 / 11，无需管理员权限。

1. 在 [Releases](https://github.com/Lreb2006/TomatoTopmost/releases/latest) 下载 `TomatoTopmost-1.0.0-windows.zip`。
2. 完整解压，双击 `Install.cmd` 安装。
3. 也可以直接双击 `TomatoTopmost.exe`，免安装使用。

## 使用

- 点击小窗口里的“置顶”按钮，即可开启或关闭。首次默认关闭，之后记住上次选择。
- 关闭小窗口后，助手仍在托盘运行。双击托盘图标可重新打开，右键可开关置顶、设置开机启动或退出。
- 建议关闭番茄ToDo自带的置顶，只用助手控制。番茄ToDo里的开关不会关闭助手。
- 如需卸载，在 Windows 已安装应用中找到“番茄置顶助手”并卸载。
